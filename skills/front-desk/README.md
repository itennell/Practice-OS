# Front Desk helper

A practice phone number (Twilio). Missed calls go to voicemail; the voicemail is transcribed, safety-checked, and the caller gets a text with open consult times from Cal.com. Callers can text to book, reschedule or cancel. Also a web chat for the practice website.

Logistics only (Illinois HB 1806): no therapy advice, no emotional support phrases, no guessing someone's mood. A plain-code crisis check runs before the model on every message and transcript. The front desk says it is an AI assistant on first contact.

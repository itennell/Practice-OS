# Referrals helper

Finds local referral sources with the free NPPES NPI Registry API, tracks them on a pipeline board, drafts outreach letters and sets follow-up reminders.

Letters are never sent by Aeon. After the clinician approves a letter, it is saved as a Gmail draft addressed to the test inbox (TEST_INBOX_EMAIL), and the clinician sends it herself. Letters never go to real providers found in NPPES. Nothing of value is ever offered or paid for a referral.
